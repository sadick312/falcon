            First-time setup
            
    
                
  1. 
                    Open a game page. Falcon replaces it automatically:
                    
    
                        sandbox.moomoo.io
                        sandbox.moomodding.io
                    
    
                
    2. 
                
  2. Pick a server, enter a name and press Enter to play.
    3. 
                
  3. Press Esc in game to open or close the Falcon menu. Use the search box to find a
                    setting.
    4. 
                
  4. After rebuilding (npm run build), click the reload icon on Falcon in
                    chrome://extensions, then reload the game tab.
    5. 
            

            
        


        

            Something isn't working?
            
    
                
  • The game looks normal, no Falcon: reload the game tab. Falcon only runs on
                    the two pages above, over https.
    • 
                
  • "Falcon could not start" on the page: the box says which step failed. Run
                    npm run build, reload the extension, then reload the game tab.
    • 
                
  • Status says files are missing: the extension was built without the mod.
                    Run npm run build (not only npm run ext:build).
    • 
                
  • Stuck on a connection error: the server may be full or down; pick
                    another server in the server list.
